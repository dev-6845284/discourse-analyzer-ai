Discourse Analyzer AI Feature Roadmap

Suggested high-impact improvements focused on analysis depth, projects and reports, search UX, auditability, and LLM transparency.

Scope: Web + Node/Mongo backend

Overview

The current app already supports quote search, analysis, and storage across multiple LLM providers. The roadmap below focuses on five next-step improvements ranked by impact and effort.

Analysis depth Projects & reporting Search UX Auditability LLM transparency

Priority Features

A Per‑Person Analysis Dashboard
Impact: High Difficulty: Medium

For each person, surface an analysis overview that aggregates all stored quotes: category distribution, average ratings, and simple timelines to show how discourse changes over time.

  • Expose a backend summary endpoint per person (category & rating stats, time buckets).
  • Create a PersonDashboard UI hooked into PersonManager / stored quotes view.
  • Start with lightweight bar/line charts; later extend to comparisons and trends.
FocusAnalytical depth & insight
Phase 2
B Projects (Saved Analyses)
Impact: Very High Difficulty: Medium–High

Introduce projects as first‑class entities: named analysis workspaces that bundle search parameters, selected quotes, and analyst notes into something reusable and shareable.

  • Add a Project model and API (CRUD, quote linking, ownership).
  • New “Projects” tab: list, open, rename, and delete projects.
  • Inside a project: dedicated view with selected quotes and a notes panel.
FocusWorkflow & collaboration
Phase 2
C Export & AI‑Generated Reports
Impact: High Difficulty: Medium

From a project or current result set, let users export quotes and analyses as JSON/CSV and trigger AI‑generated narrative reports summarising key themes and contradictions.

  • Implement export.ts utilities for JSON/CSV export from the browser.
  • Add a backend “generate report” endpoint leveraging existing LLM services.
  • Use a ReportModal to preview, tweak, and download Markdown/PDF.
FocusDeliverables & sharing
Phase 3
D Advanced Search & Filters for Stored Quotes
Impact: Medium–High Difficulty: Medium

Strengthen navigation across growing datasets with robust filters and keyword search over stored quotes, analysis metadata, and notes.

  • Extend the stored‑quote API with text, person, date, rating, language, and provider filters.
  • Create useStoredQuoteFilters and a dedicated filter bar above StoredQuotes.
  • Persist last‑used filters in localStorage to streamline frequent workflows.
FocusUsability & retrieval
Phase 1
E Audit & Attribution Metadata
Impact: Medium Difficulty: Low–Medium

Capture who ran which analysis with which provider, when, and surface that metadata alongside each quote to improve trust and compliance.

  • Extend Quote schema with audit fields (user, provider, timestamps, source mode).
  • Propagate current user and provider through useQuotes into save/analyse endpoints.
  • Show a concise “meta” line in quote cards and stored‑quotes detail views.
FocusGovernance & trust
